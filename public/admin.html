Mode maintenance

Quand le mode maintenance est activé, le site affiche une page de maintenance à tous les visiteurs. Seul l'accès admin reste disponible. Un mot de passe permet de contourner la maintenance.

Mot de passe de contournement

Ce mot de passe permet d'accéder au site même en mode maintenance. Ajoutez ?bypass=MOTDEPASSE à l'URL du site.
